# 네이버 파워링크 광고 귀속 실매출 보고서

Marketing Intelligence의 **네이버 실매출** 탭에서 KST 시작일과 종료일을 정하고 일·주·월 단위와 유입 브랜드를 선택합니다. 비교는 직전 동일 길이입니다. 광고비와 ROAS로 브랜드를 정렬할 수 있습니다. 주문 및 상품 근거와 Excel은 기존 운영자 인증 범위에서 제공합니다.

## 원천과 집계

- 운영에서는 기존 Cafe24 Analytics CRM 수집 스케줄이 저장한 주문 유입 스냅샷을 먼저 사용합니다. 태깅 이후 누락 구간은 기존 Analytics 조회로 보강합니다. Admin 주문 조회와 매출·클레임 계산도 기존 경로를 사용합니다.
- 네이버는 일별 통계에 단일 ID를 받습니다. 기존 서명 클라이언트로 캠페인과 광고그룹을 조회합니다. 전체는 캠페인, 브랜드는 광고그룹 통계를 사용합니다. 그룹 통계에 두 세대의 실제 소재 비용이 포함되므로 소재 비용을 그 위에 다시 더하지 않습니다.
- `config/naver-attribution-creatives.json`은 확인된 교체 141개와 604SERVICE 레거시 태그 1개를 보관합니다. 새 교체 시 기존·신규 ID와 적용 및 중지 시각을 동일 논리 소재에 기록합니다. 브랜드 코드 미확정 그룹은 미분류로 표시합니다.
- Cafe24 주문일 기준으로 주문번호를 한 번 계산합니다. 브랜드는 유입 그룹과 실제 구매 상품을 따로 표시합니다. 미결제와 전체 취소는 유효 주문에서 제외하고 부분취소는 잔존 결제에 한 번 반영합니다. 신규·재구매 이력이 확인되지 않은 경우 미확인 상태를 표시합니다.
- 광고비 및 ROAS에는 기간과 광고그룹 커버리지가 적용됩니다. 이미 연결된 일부 주문은 근거로 볼 수 있으며, 추적이 미완료된 기간의 전체 귀속액과 ROAS 계산은 보류합니다. 광고 플랫폼 전환금액과 Cafe24 순매출은 독립 지표입니다.
- 기존 CRM 수집기 활성 설정 `CRM_ANALYTICS_COLLECT=on`의 일별 성공 이후 기본 보고서 캐시를 데웁니다. 보고서 요청도 15분 캐시 만료 후 자동 갱신하므로 장시간 열린 화면에서는 다시 조회할 수 있습니다. 기존 주간 보고서에서 동일 자료가 필요한 경우 `readNaverAttributionReport({ since, until, grain: 'week' })`를 주간 모델의 실매출 블록으로 연결할 수 있습니다.
