# VEIL FOUND — source-only ChatGPT release

POST /api/ai-audit/veil-found/mcp uses existing x-samplas-internal-token / AI_AUDIT_SECRET auth. Five tools: getUploadStatus, previewReadyPosts, scheduleUpload, runUpload, getUploadHistory. Read arguments are {}. Writes require {approval:true,requestId,posts}; schedule also needs scheduledAt (future ISO time with explicit offset). Each post is exactly {number,path,revision,caption} from preview. Show exact posts and time to user and obtain explicit approval before writes; never infer approval.

READY/#25.png through #34.png match READY/VEIL_FOUND_025-034/025/caption.txt through 034/caption.txt. Direct READY/NNN/caption.txt and other numeric range folders are supported. Missing/ambiguous files fail closed. Caption must have four nonempty lines: VEIL FOUND #NNN, brand, product, KRW/원 price or SOLD OUT. No invented values. Original image URL is sent without conversion, resizing or cropping. PNG selection/submission is implemented, but live Meta PNG acceptance is not verified or guaranteed; Meta documentation historically specifies JPEG-only publishing. No live container creation or Instagram POST was performed.

Friday 20:00 KST polling is retained. Manual state is separate from Friday counters. Real Instagram feed duplicates, source revision and exact caption are rechecked. Incomplete feed pagination fails closed. Source moves only follow Instagram-confirmed publication or original already-published reconciliation. Preview never moves anything.

WORK_DIR/veil-found-control.json stores requests/history with atomic rename and exclusive file lock. Same requestId/same payload returns previous result; changed payload conflicts. Unknown/running requests are never automatically retried. Investigate stale locks and real Instagram feed manually, never delete locks automatically. Publication followed by move failure retains its published event. WORK_DIR must be a persistent single-instance volume; distributed scheduling is not supported. One-time execution is disabled unless VEIL_FOUND_ONCE_ENABLED=true. Activation requires separate approval. Due pending schedules execute once, including after restart; confirm missed-time policy before production activation.

Private Site source: veil-found-plugin/. Build with npm run build and npm run validate in that directory. Sites supplies trusted user identity; SAMPLAS_INTERNAL_TOKEN remains a server Secret. No Site has been registered/published in this source-only release. Backend deployment, private plugin publication, authenticated production READ checks and scheduler activation remain separate. Until then normal ChatGPT cannot call these tools. Existing Popup/Seeding plugins are unchanged.
